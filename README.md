This is a data analysis that looks at a dataset called hcmst, which looks at relationship statuses during COVID, it can be found at https://diverse-data-hub.github.io/data/clean/hcmst.csv. The files involved are listed below:

- MiniDataAnalysis1.qmd
- Mini Data Analysis.Rproj\

To reproduce the analysis, open Mini Data Analysis.Rproj in RStudio and then open MiniDataAnalysis1.qmd. Make sure the required R packages listed at the beginning of the document are installed and loaded. The Quarto document can then be rendered to reproduce the analysis and results.
